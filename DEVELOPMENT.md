# 👏 Clap Clap — Development

## Layout

```
src/shared/   → ReplicatedStorage.Shared          (Config, Formulas, Num, Format, Sounds)
src/server/   → ServerScriptService.Server        (init.server.luau + services)
src/client/   → StarterPlayerScripts.Client       (init.client.luau + controllers)
build/        → Studio scripts that (re)build the stage worlds into workspace.Stages
tools/        → pacing simulator, checksum sync check
docs/         → design docs
```

`default.project.json` maps the same layout for [Rojo](https://rojo.space), so switching to Rojo later is drop-in.

## Current workflow (no Rojo yet)

`src/` is the source of truth. Scripts are pushed into Studio through the Roblox Studio MCP
(`execute_luau` / `multi_edit`). After a push, compare:

```bash
python tools/checksums.py
```

with the output of `tools/studio_checksums.luau` run in Studio. Every line should match.

World geometry is generated by the scripts in `build/`. Re-running one replaces that stage's model.
`build/place_settings.luau` sets place properties the game depends on (StreamingEnabled **off**:
local destruction needs whole stage models on every client) and lists the settings that must be set
by hand after publishing (Max Players 20, Studio API access).

## Saving

`DataService` uses a session lock in the save record so two servers never write the same player at
once: a joining server waits for the previous one to release (force-takes after 30 s), saves only
write while the lock is still ours, and a player is kicked rather than given a blank profile if
loading fails. Unpublished places, or places without Studio API access, use in-memory data.

## Multiplayer test

Studio → **Test** tab → *Clients and Servers* → 2 players → **Start**. Check: both seated in
neighbouring hall seats, each sees the other's arms move with smaller rings, clapping on the beat
together shows **IN SYNC**, the Standing Ovation fires for both, a breakthrough by one player
shows a banner to the other.

**Save the place file** (File → Save to File) as `ClapClap.rbxl` in this folder. The Studio place
holds the built worlds; the scripts can always be re-pushed from `src/`.

## Testing in Studio

- Saving is disabled while the place is unpublished (in-memory data; a warning prints on start).
- Studio-only cheat for fast-forwarding, from the **Server** datamodel during play:
  `game.ServerStorage.DevGrant:Invoke(0, applauseLog10, techniquesUpToStage)`
  e.g. `DevGrant:Invoke(0, 8, 1)` adds 10⁸ Applause and all stage-1 techniques to every player.

## Tuning

Economy numbers live in `src/shared/Config.luau`. Re-check pacing after changes:

```bash
python tools/pacing_sim.py 6
```

(argument = clicks per second). Current target: stages 1–3 clear at about 3 / 7 / 12 minutes.
